# KOLOSI : Système de gestion de stock

Application permettant de gérer les produits et les mouvements de stock avec
une vue globale sur toutes les activités de la boutique.

## Technologies utilisées

Pour la réalisation de KOLOSI, nous avons utilisé des technos modernes et flexibles :

- React 
- Tailwind
- Express
- MySQL

## Fonctionnalités 

KOLOSI possède plusieurs fonctionnalités comme :
- La gestion des produits
- La gestions des mouvents 
- La gestion des stock
- La gestion des utilisateurs
